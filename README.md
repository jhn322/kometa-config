# PSD Templates for Kometa

This branch contains the original **Photoshop (PSD) template files** used as the foundation for many of the graphics in my main [Kometa Config](../) repository.

All templates are fully editable `.psd` files, making it easy to customize the designs, text, colors, and layouts to suit your own specific Plex setup.

## 📁 Templates

- **Actors**
- **Audiobook Genres**
- **Genres**
- **IMDb**
- **Letterboxd**
- **MAL**
- **Metacritic**
- **Music Genres**
- **Oscars**
- **Random**
- **Rotten Tomatoes**
- **Separator**
- **Streaming Services**
- **Studios**
- **TMDb**
- **Trakt**
- **TV Networks**
- **Best Of**
- **Decade**

> These templates are not required if you're happy using the already provided posters in the main Kometa config.

## 📋 Supported Libraries

| Library Type   | Status              |
| -------------- | ------------------- |
| 🎬 Movies      | Active              |
| 📺 TV Shows    | Active              |
| 🏮 Anime       | Active              |
| 🎵 Music       | Active              |
| 🎞️ Remux       | Active              |
| 📚 Audiobooks  | Disabled by default |
| 🎼 Soundtracks | Disabled by default |
| 🎥 Videos      | Disabled by default |
